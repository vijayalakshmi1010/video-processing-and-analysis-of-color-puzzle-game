# video-processing-and-analysis-of-color-puzzle-game
A cognitive skill assessment platform using video of playing puzzle and giving an automatic complete analysis report.

Enabled doctors and teachers to analyse the cognitive ability of children in a systematic and computerised manner.

Includes:
Color recognition using computer vision,
HSV color segmanetation,
object detection with contour analysis,
centroid calculations for block positions,
puzzle accuracy calculayion,
time taken analysis,
automated performance report generation.
